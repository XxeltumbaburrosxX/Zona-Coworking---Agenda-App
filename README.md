# Zona Coworking — Plataforma de Gestión y Reservas

Sistema integral para la administración de salas, cronograma de actividades, control financiero de abonos y reportes de métricas para Zona Coworking.

View your app in AI Studio: https://ai.studio/apps/003b1e44-8821-45c4-83ef-4541d146bff1

## Características Principales

* **Agenda y Ocupación en Tiempo Real:** Gestión de reservas, reuniones y recordatorios con prevención de colisiones de horario.
* **Programación de Fechas Múltiples:** Reserva de talleres y cursos en períodos continuos de una sola vez.
* **Pre-reservas y Confirmaciones:** Apartado de espacios preventivo con avisos de vencimiento.
* **Control Financiero:** Registro de abonos en divisas y bolívares, cálculo de saldos pendientes y liquidación de comisiones comerciales.
* **Métricas y Reportes:** Dashboard analítico con comparativas multiperíodo y márgenes de coworking.

## Ejecución Local

**Prerrequisitos:** Node.js (v18+)

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```
